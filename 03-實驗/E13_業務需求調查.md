# 實驗紀錄：E13 業務陌生開發時順便做需求調查

| 欄位 | 內容 |
|---|---|
| 負責人 | Vincent（設計）／負責陌生開發的業務（執行） |
| 漏斗階段 | 獲客前的需求驗證 |
| 開始日期 | 待定 |
| 結束日期 | 收滿 30 份回覆為止 |
| 狀態 | 🟡 準備中（需要確認業務能否配合） |

## 1. 假設
如果業務在陌生開發時，順便問潛在客戶最需要哪一種作品（產品介紹／資訊傳遞／AI 短劇），我們就能知道**第一場工作坊該主打哪個方向**，不用憑感覺決定。

## 2. 做法：業務陌生開發時多問 5 題（約 1 分鐘）

> 業務可以這樣開場：「我們最近在規劃一堂 AI 實作課，想請教您兩三個問題，大概一分鐘，可以嗎？」

| # | 問題 | 選項 |
|---|---|---|
| 1 | 您是做哪一行的？ | 自由填寫 |
| 2 | 平常工作中，哪一件事最花時間？ | A. 跟客戶介紹產品　B. 寫貼文、公告、通知　C. 做宣傳影片　D. 其他：＿＿ |
| 3 | 平常工作上，比較常用手機還是電腦？ | A. 幾乎都用手機　B. 手機電腦差不多　C. 幾乎都用電腦 |
| 4 | 如果有一堂 2 小時的課，下課就能帶走一個做好的作品，您最想要哪一個？ | A. 產品介紹（文案或簡報）　B. 資訊貼文　C. AI 短影片／短劇 |
| 5 | 開課時要不要通知您？方便留個 LINE 或電話嗎？ | 願意留／不用 |

**第 5 題最重要。** 人「說」有興趣很容易，願意留聯絡方式才是真的有興趣。統計時，要特別看「選某個方向、而且願意留聯絡方式」的人有多少。

## 3. 記錄表（業務每問完一位就填一列）

建議用 Google 試算表，或直接把下面這張表貼給業務。

| 日期 | 行業 | Q2 最花時間 | Q3 手機或電腦 | Q4 最想要的作品 | Q5 願意留聯絡方式 | 聯絡方式 | 備註（客人原話） |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

## 4. 成功標準（事先寫好）
- 收滿 **30 份**再下結論，太少的話容易被少數人帶偏。
- 某個方向的「選擇人數 × 願意留聯絡方式的比例」明顯最高，就用它當第一場工作坊的主打。
- 如果三個方向差不多，就用 Q2 的「最花時間的事」當第二個判斷依據。
- Q3（手機或電腦）的結果用來決定工作坊和教材的形式，見下方「Q3 結果怎麼用」。

## Q3 結果怎麼用（手機或電腦）

| 如果多數人… | 工作坊和教材要這樣調整 |
|---|---|
| **幾乎都用手機** | 工作坊全程用手機操作；模板做成手機上好填的格式；教學影片拍直式；作品以 LINE、Threads、IG 能直接分享的格式為主 |
| **手機電腦差不多** | 工作坊用電腦教，但每個步驟都示範「回家用手機怎麼做」 |
| **幾乎都用電腦** | 工作坊請學員帶筆電；可以教比較完整的流程，例如做簡報、剪影片 |

也可以交叉看：**不同行業**和**想要的作品**，是不是跟手機或電腦有關。例如想做 AI 短劇的人，是不是大多用手機？這些結果也會一併提供給產品團隊，參考 AI Token King 的手機版要不要優先加強。

## 5. 加分
- 願意留聯絡方式的人，就是**第一場工作坊的邀請名單**。調查做完的同時，招生也開始了。
- 「備註」欄請業務盡量寫客人的**原話**，之後可以直接用在課程介紹和廣告文案裡。
