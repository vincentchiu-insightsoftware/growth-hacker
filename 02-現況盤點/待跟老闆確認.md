# 待跟老闆確認清單

> 訪談中遇到需要老闆拍板或提供資訊的問題，都先記在這裡，最後一次整理後找老闆討論。

| # | 來源 | 要確認的事 | 為什麼重要 | 老闆的回覆 |
|---|---|---|---|---|
| 1 | Q2 | AI 小白自己註冊（沒參加工作坊）後，第一個畫面是什麼？有沒有新手引導、範本或教學？ | 決定自助路徑的啟用率。沒有引導的話，小白很可能註冊完就流失 | |
| 2 | Q2 | 能不能在註冊後放「工作範本」（例如：幫我寫給客戶的產品介紹），讓小白 5 分鐘內完成第一件事？需要深圳團隊改嗎？ | 這是設計 Aha Moment 最直接的方式 | |
| 3 | Q2 | 工作坊用的測試帳號，結束後怎麼處理？學員要怎麼轉成自己的付費帳號？ | 測試帳號轉付費是工作坊路徑最可能漏掉客戶的地方 | |
| 4 | Q4 | 目前付費客戶大約有多少位？他們大多從哪裡知道 AI Token King（人脈介紹、搜尋、社群、業務開發……）？介紹人是不是「會教入門 AI、有自己學生」的人？ | 知道現有客戶從哪裡來，才能決定要加碼哪個管道 | |
| 5 | Q5 | 公司目前認識幾位「會教入門 AI、有學生或粉絲」的人？能不能找 3～5 位試行合作夥伴計畫？獎勵要用分潤（占首次儲值的幾 %）還是送免費額度？產品毛利能負擔多少？ | 合作夥伴是成本最低的獲客方式，但獎勵比例取決於毛利 | |
