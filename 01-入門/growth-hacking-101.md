# Growth Hacking 101（給完全新手）

## 1. 核心觀念：成長是「實驗」出來的

傳統行銷：先想一個大計畫 → 花一大筆錢 → 等結果。
Growth Hacking：想很多小點子 → 挑最划算的先試 → **用數字判斷**有沒有效 → 有效就加碼，沒效就換下一個。

```
  想點子 → 排優先 → 做實驗 → 看數據 → 學到什麼
     ↑                                   │
     └───────────── 每週循環 ─────────────┘
```

重點不是每個實驗都成功（大部分會失敗），而是**轉得夠快**。一週試 2 個，一季就有 20+ 次學習。

---

## 2. 北極星指標（North Star Metric）

全公司只盯**一個**最能代表「客戶真的得到價值」的數字。

AI Token King 的候選（待你確認）：

| 候選 | 優點 | 缺點 |
|---|---|---|
| **每週有實際消耗 Token 的付費帳戶數** | 代表客戶真的在用、會再儲值 | 需要後台能查 |
| 每月 Token 消耗總金額 | 直接連到營收 | 容易被一兩個大客戶扭曲 |
| 新註冊數 | 好量 | 註冊了不用 = 沒價值，**不建議** |

> 建議先用第一個。

## 3. AARRR 海盜漏斗

把客戶從「沒聽過你」到「幫你推薦」拆成 5 關，找出**哪一關漏最多**，先修那一關。

| 階段 | 英文 | 問的問題 | AI Token King 的例子 |
|---|---|---|---|
| 1. 獲客 | Acquisition | 人從哪裡來？ | 從 Google 搜「GPT API 台幣」、Threads 貼文、KOL 介紹進到官網 |
| 2. 啟用 | Activation | 第一次有沒有感受到價值？ | 註冊後 **24 小時內成功打出第一次 API 呼叫** |
| 3. 留存 | Retention | 會不會一直回來用？ | 第 2 個月還有在消耗 Token |
| 4. 營收 | Revenue | 有沒有付錢、付多少？ | 第一次儲值、再次儲值、儲值金額變大 |
| 5. 推薦 | Referral | 會不會介紹別人？ | 推薦朋友註冊、雙方各得額度 |

**新手最常犯的錯**：一直砸錢在第 1 關（買流量），但第 2、3 關漏光光——等於往破水桶倒水。

## 4. ICE 評分：決定先做哪個實驗

每個點子打三個分數（1～10 分）：

- **I**mpact 影響力：成功的話，對北極星指標幫助多大？
- **C**onfidence 信心：有多少把握會成功？（有數據或前例＝高）
- **E**ase 容易度：多快、多便宜能做完？（不用工程師＝高）

**ICE 分數 = (I + C + E) ÷ 3**，分數高的先做。不用很精準，目的是逼自己比較。

---

## 5. 一個好實驗的格式

```
假設：如果我們 ___（做什麼），
     那麼 ___（哪個指標）會 ___（提升多少），
     因為 ___（理由）。
做法：___
期間：___（通常 1～2 週）
成功標準：___（事先寫好數字，避免事後自圓其說）
```

範例：
> 假設：如果新用戶註冊時送 NT$30 試用額度，那麼「註冊後 7 天內首次儲值率」會從 ?% 提升到 ?%，因為用戶能先免費確認服務穩定。
> 成功標準：首次儲值率提升 ≥ 30%，且試用成本 < 新增營收。

## 6. 名詞小抄

| 名詞 | 意思 |
|---|---|
| 轉換率 | 從上一關走到下一關的比例 |
| CAC | 取得一個付費客戶要花多少錢 |
| LTV | 一個客戶一輩子總共貢獻多少營收。健康標準：LTV ≥ 3 × CAC |
| 流失率（Churn） | 本月有用、下月不用了的比例 |
| A/B 測試 | 同時給兩組人看不同版本，比較哪個好 |
| ICP | 理想客戶輪廓：最適合你、最容易成交的那種客戶 |
| UTM | 加在網址後面的追蹤碼，用來知道流量從哪個貼文／管道來 |
