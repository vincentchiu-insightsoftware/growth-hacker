# growth-hacker — AI Token King 成長駭客專案

用 Growth Hacking 的方法，替 **AI Token King**（aitokenking.com.tw）找到可重複、可量測的成長方式。

> 這個專案**不需要會寫程式**。全部用 Markdown 文件運作：Vincent 填資料、做決定，Claude 負責分析、出點子、整理紀錄。

---

## 一句話說明 Growth Hacking

**不靠大筆廣告預算，而是用「小實驗 → 看數據 → 留下有效的、砍掉沒效的」這個循環，快速找出讓產品成長的方法。**

## 資料夾地圖

| 資料夾 | 用途 | 誰負責 |
|---|---|---|
| `01-入門/` | Growth Hacking 新手教材（看懂名詞與框架） | Claude 寫，Vincent 讀 |
| `02-現況盤點/` | AI Token King 目前的數字與狀況 | **Vincent 填**，Claude 分析 |
| `03-實驗/` | 實驗點子清單（Backlog）＋每個實驗的紀錄 | 一起 |
| `04-流程/` | 每週成長會議怎麼開、怎麼做決定 | Claude 定，Vincent 執行 |
| `agents/` | Growth Hacker AI 角色設定，可用 `@GrowthHacker` 呼叫 | Claude |

## 新手起步三步驟

1. **讀** `01-入門/growth-hacking-101.md`（約 10 分鐘）
2. **答** `02-現況盤點/問題總表.md` 裡的問題：跟 Claude 說「繼續問我」，Claude 會一題一題問（不知道的說「不知道」就好，這本身也是重要資訊）
3. **選** `03-實驗/實驗清單.md` 裡你覺得最想先試的 1～2 個，Claude 會幫你展開成可執行的計畫

## 怎麼跟 Claude 合作

直接用中文講就好，例如：

- 「我填好問卷了，幫我分析」
- 「實驗 E03 的結果是 ___，幫我記錄並判斷要不要繼續」
- 「這週成長會議開始」
- 「幫我把 E05 寫成可以交給 Penny 執行的任務單」
